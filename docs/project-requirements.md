# 项目需求 · Project Requirements

> 适用范围：在校模拟器 (School Broadcast Simulator)
> 最后更新：2026-06-19

---

## 项目简介

**在校模拟器**是一个基于 Web 的校园作息铃声模拟器。用户点击"开始"后，系统按照预设的作息时间表（默认：中国夏季学校作息表），在对应时间播放对应的 MP3 铃声。支持自定义时间表上传/下载、番茄钟倒计时、随机音乐等功能。

**访问地址**：https://keyboard-society.github.io/school-broadcast-simulator/

---

## 核心功能（已完成，本次不修改）

1. 按时间表自动播放铃声
2. 自定义作息表（上传 JSON / 下载 / 重置）
3. 当前时间 & 下班倒计时显示
4. 下一个事件预览卡片（含试播 & 音量调节）
5. 番茄钟倒计时（默认时长 + 自定义，含进度圈）
6. 随机音乐选项

## 本次改造需求：Apple 风格视觉升级

### 背景

当前 UI 使用 antd 默认样式 + 深海军蓝 Header/Footer，视觉粗糙，看起来像前端初学者的练习项目。

### 目标

- 将视觉改为 **Apple 官网风格**：简洁、干净、有质感
- 纯视觉改造，**不改任何业务逻辑**
- 保留 antd，用 `ConfigProvider` 深度定制主题
- 布局结构保持不变（Header + Sider + Content + Footer）

### 风格关键词

- 大量留白
- 柔和暖灰底色 (`#f5f5f7`)
- 白色卡片浮在灰底上
- 毛玻璃（Header）
- 大圆角 (12-16px)
- 柔和浅阴影
- 克制的色彩（品牌蓝 `#0071E3`）
- 系统原生字体

### 非目标（本次不做）

- 暗色模式
- 移动端/响应式
- 交互动效（除基础 hover 外）
- 国际化
- 用户登录/账号
- 新增功能
