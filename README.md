# 🏫 校园作息铃声模拟器

[![在线访问](https://img.shields.io/badge/在线访问-GitHub%20Pages-blue?style=for-the-badge)](https://keyboard-society.github.io/school-broadcast-simulator/)

基于 React + Ant Design 的 Web 校园作息铃声模拟器，在浏览器中按预设时间表播放 MP3 铃声，帮你找回校园时光的仪式感。

## ✨ 功能特点

- 🕐 **实时时钟显示** - 支持普通/翻牌/LED 三种显示模式
- ⏰ **智能铃声播放** - 按预设时间表自动播放铃声
- 🍅 **番茄钟功能** - 内置番茄工作法计时器
- 📅 **时间表管理** - 自定义作息时间表
- 🌙 **暗色模式** - 自动适应系统主题
- 📱 **响应式设计** - 完美适配桌面端和移动端

## 🚀 快速开始

### 环境要求

- Node.js >= 20.10.0
- pnpm (推荐)

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/keyboard-society/school-broadcast-simulator.git

# 进入目录
cd school-broadcast-simulator

# 安装依赖
pnpm install

# 启动开发服务器
pnpm start

# 构建生产版本
pnpm build
```

## 🛠️ 技术栈

- **框架**: React 18 + TypeScript 4
- **UI 组件库**: [Ant Design 5](https://ant-design.antgroup.com/)
- **构建工具**: Create React App (react-scripts 5)
- **时钟动画**: [Flipclock.js](https://flipclockjs.com/)
- **包管理**: pnpm
